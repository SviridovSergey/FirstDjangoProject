# Django Survey System - Система опросов на Django

## Полный гайд по созданию и запуску

### Что это такое?
Полнофункциональная система для создания и прохождения опросов с поддержкой различных типов вопросов: текстовые ответы, одиночный выбор, множественный выбор.

### Возможности системы
- Создание неограниченного количества опросов
- Три типа вопросов: текст, один вариант, несколько вариантов
- Удобная админ-панель для управления
- Адаптивный и чистый дизайн
- Защита от CSRF-атак
- Сбор базовой статистики (IP, время ответа)

### Технологический стек
- **Backend:** Django 5.2 + Python 3.8+
- **Database:** SQLite3 (легко заменить на PostgreSQL/MySQL)
- **Frontend:** HTML5 + CSS3 + Django Templates
- **Security:** CSRF protection, XSS protection

##  Полная инструкция по запуску

### Предварительные требования
- Установленный Python 3.8 или выше
- Установленный pip (менеджер пакетов Python)
- Браузер для просмотра результатов

###  Пошаговая установка и запуск

#### Шаг 1: Клонирование и настройка проекта
```bash
# Клонируйте проект (если используете Git)
git clone <https://github.com/SviridovSergey/FirstDjangoProject>
cd FirstDjangoProject

# Или создайте папку проекта и скопируйте файлы
```

#### Шаг 2: Установка зависимостей
```bash
# Установите Django
pip install django
```

#### Шаг 3: Настройка базы данных
```bash
# Примените миграции для создания структуры БД
python manage.py migrate

# Создайте суперпользователя для доступа к админке
python manage.py createsuperuser
```
**При создании суперпользователя введите:**
- Имя пользователя (username)
- Email (можно пропустить)
- Пароль (дважды для подтверждения)

#### Шаг 4: Запуск сервера
```bash
# Запустите development сервер
python manage.py runserver 8080
```

#### Шаг 5: Доступ к приложению
- **Главная страница опросов:** http://127.0.0.1:8080/polls/
- **Административная панель:** http://127.0.0.1:8080/admin/

### Работа с системой

#### Создание опросов (через админку)
1. **Войдите в админку** по ссылке http://127.0.0.1:8080/admin/
2. **Добавьте новый опрос:**
   - Нажмите "Add" рядом с "Surveys"
   - Заполните название и описание
   - Убедитесь, что опрос активен (is_active)

#### Добавление вопросов
1. **В разделе Questions нажмите "Add":**
   - Выберите опрос из выпадающего списка
   - Введите текст вопроса
   - Выберите тип вопроса:
     - **Text** - текстовый ответ
     - **Single** - выбор одного варианта
     - **Multiple** - выбор нескольких вариантов
   - Укажите порядковый номер (для сортировки)

#### Добавление вариантов ответов
1. **Для вопросов с выбором создайте варианты:**
   - В разделе Choices нажмите "Add"
   - Выберите соответствующий вопрос
   - Введите текст варианта ответа

### Типы вопросов в системе

1. **Текстовый ответ (Text)**
   - Пользователь вводит произвольный текст
   - Идеально для открытых вопросов, отзывов

2. **Один вариант (Single Choice)**
   - Пользователь выбирает ОДИН вариант из предложенных
   - Отображается как радио-кнопки
   - Подходит для рейтингов, однозначных ответов

3. **Несколько вариантов (Multiple Choice)**
   - Пользователь выбирает НЕСКОЛЬКО вариантов
   - Отображается как чекбоксы
   - Идеально для вопросов "Что вам понравилось?"

### Пример использования

**Сценарий: Опрос удовлетворенности клиентов**

1. **Опрос:** "Оценка нашего сервиса"
2. **Вопрос 1:** "Ваше имя" (текстовый)
3. **Вопрос 2:** "Общая оценка" (один вариант)
   - Отлично, Хорошо, Удовлетворительно, Плохо
4. **Вопрос 3:** "Что можно улучшить?" (несколько вариантов)
   - Скорость работы, Интерфейс, Функциональность, Поддержка

### Возможные проблемы и решения

**Проблема:** "No installed app with label 'polls'"
**Решение:** Добавьте 'polls' в INSTALLED_APPS в settings.py

**Проблема:** "Error: You don't have permission to access that port"
**Решение:** Используйте другой порт: `python manage.py runserver 8080`

**Проблема:** "404 Page Not Found"
**Решение:** Откройте правильный URL: http://127.0.0.1:8080/polls/

**Проблема:** "Нет доступных опросов"
**Решение:** Создайте опросы через админ-панель
